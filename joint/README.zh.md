# JOINT C002：两个独立复耦合的完整体磁化率

作者：Dehao Lin，中山大学物理学院；[ORCID](https://orcid.org/0009-0001-4551-8490)。

本结果是共享 Lean 数学库中的第四项独立成果，保留定理 1.1 ∧ 定理 1.2 ∧ 推论 1.3 的完整 J/R/I 范围。J 包括两个独立复变量、未平方谱集、物理高低温分支、所有格点和全部奇偶粒子阶、正规收敛、固定混合导数、每个有限边界点的不可延拓性及横截曲线与紧参数族结论。R 对每个有限正耦合比保留精确拉回域和同一切片内的不可延拓；λ=1 使用独立机制。I 包括完整高温单位圆盘与低温连通加相外域、原点与同点项、全部级数、归一化、覆盖变换群及整个单位圆。
