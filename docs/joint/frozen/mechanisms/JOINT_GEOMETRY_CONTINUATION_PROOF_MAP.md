## Genuine topology hypotheses and exclusions

1. `UnramifiedHolomorphicDomain M` contains an arbitrary topological space M, a projection, an actual open partial homeomorphism of that projection at every point, and a function holomorphic in those charts. It mentions neither the physical domain nor its function. Thus it describes ordinary unramified continuation data, not a structure whose fields already assert nonextension. It does not require Hausdorffness, making the impossibility theorem stronger; every ordinary Hausdorff Riemann domain is covered.
2. The starting hypothesis is equality of ordinary germs at one initial point over D. Equality at later points is proved by holomorphic uniqueness and connectedness. The finite path is any continuous path upstairs. There is no premise that the path has a first exit, no premise that the terminal point lies in the spectral set, and no premise that chart agreement already extends to a component.
3. The intermediate first-exit chart theorem takes a positive time with all earlier projected points in D. The outer finite-path theorem derives such a time internally if a point lies outside. The component used in the contradiction is constructed from a connected final path segment in the chart.
4. The domain is an actual open subset of finite-dimensional C². Its local connectedness makes components of open intersections open; this is a standard topology fact used explicitly in the proof. The holomorphic identity theorem then extends a genuine local equality to that whole component.
5. The LT covering uses restricted exponential followed by an actual Joukowski homeomorphism. It does not assert a globally single-valued inverse temperature on the exterior. The susceptibility descends because its actual spectral data are invariant; the energy-field beta factor remains on the prescribed physical temperature continuation.
6. No inference from ambient nonextension to restriction nonextension occurs in this geometric bridge. The only automatic direction used is restriction of a purported ambient extension to an independently proved obstructed transversal.
