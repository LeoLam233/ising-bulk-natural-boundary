The adjacent displayed e_n=log(tau_n n^2/A) and exact L(n,j) already use this normalized quantity. The correction makes the explanatory sentence agree with those unchanged exact factors.
- **E-P08-04**: The corrected parity is particle number n, not derivative order k. The same radial-degree computation n^2-2-2k gives -1 (odd n) and 0 (even n), matching the logarithmic/bounded error and the unchanged first-coefficient proposition.
- **E-P08-01**: The real spin, Gibbs-state and ferromagnetic input explanations are in ana:physical, of which ana:interface is a subsection. The reference now reaches all of the named inputs; no analytic estimate is imported through it.
- **E-P08-02**: The reference is corrected to the joint normal-convergence proposition ana:normal, which supplies the actual holomorphic functions. The physical real-input subsection alone is not that construction.
- **E-P08-05**: In the isotropic exterior coefficient evaluated at 1/s, W=s^-1+O(1) and the small reciprocal quadratic root is rho=(2W)^-1+O(W^-3)=s/2+O(s^2). The ambient variable z=2Kx is different. This preserves the original one-body O(s), pair-square O(s^2), N^2 exponent and origin normalization.
- **E-P08-06**: The branch coordinate in this one-body estimate is theta-theta_b, theta_b=+/-b, and the dispersion factor is W-1.
