## 新增局部尾界究竟证明了什么

固定一个素数阶单位根和首次偶阶 N=2p，取固定导数阶数 k=N²/2−1。报告只处理 n=mN、m≥2 时，两组所有角度接近 +θ 或 −θ 的小邻域。每组用 Q=Σu_i²≤δ² 限定，截断函数不依赖径向参数 ε。

它得到的式 (22) 是

\[
 \sup_{0<\varepsilon<\varepsilon_0}
 \left|\partial_\varepsilon^k I_{n,\delta}\right|
 \le C_k\frac{n^{2k}}{n!}\rho^{n^2},\qquad 0<\rho<1.
\]

这是对无限多个 n 可求和的统一估计，超过“每个固定 n 单独有界”。但 I 是局部积分，不是完整的 A_n。

接收端重点复核如下：

1. 在先选定的解析邻域内，分子精确提出 Vandermonde 平方；剩余单体和 pair 因子的固定阶导数付出至多 `C_k n^(2j) C0^(n²)`。k 固定，不随较高粒子阶 n 增大。
2. 分母按 nε 小与大分开。前者由实部阻尼与非零二次相位提供 `|1−exp(−L_n)|≥c(nε+Q)`；后者由实部阻尼直接避免零点。径向一阶扰动在 ε=0 的虚部为零，因此相位误差记为 O(nε²)，不能在此忽略 n。
3. 对 j 阶分母导数，保留 `C_j n^j(1+Q^(−j−1))`。与分子预算合并，n 的固定次幂不超过 n^(2k)。
4. Vandermonde 次数为 n(n−1)，独立角维数为 n−1，最坏分母为 Q^(−k−1)。式 (25) 的 δ 次数为 `n²−3−2k`，与这三项相加一致。在 n≥2N 时，该积分没有不可积问题。
5. 先在较大固定邻域确定 C0，再缩小 δ，令 `ρ=2C0δ<1`；固定因子 δ^(−3−2k) 收入 C_k。该选择未把待选 δ 放回 C0 形成循环。

这些步骤支持所写的**局部**估计。在本次限定复核中没有发现具体算术或量词错误；这不是对全部有限阶局部化接口的认证。

未覆盖部分包括：每个高阶共振项中的补集、其他高阶粒子数的积分，以及其中接近 q=±1 的分支退化和相关分母。TW 的固定阶局部常数尚未被转化成对这些区域可求和的 n 一致常数。式 (22) 因此不能代替完整尾和的条件 (T)。

它与 v7 某些尾项预算同样出现按 n² 衰减的形式，并不说明已经重现 v7 的完整轮廓分割、保护圆盘或覆盖论证。局部等角区域与全域估计承担的任务不同。

## 有限截断与无限和之间的区别

第三份不仅写下局部模型，还专门尝试证明其对完整有限截断的贡献不为零：用对反射不变的角 cutoff 建立 `A_n[ψ]=O_n[ψ]+2 lim U_n,r[ψ]`，再在补集应用 TW 的局部非驻相估计。它没有直接将光滑 cutoff 当作全纯函数拖过轮廓。

这些推导已被阅读，符号、局部 beta 积分和两等角邻域的反射关系可复核。但本次未重新穷尽检查 TW 的所有局部假设及 Abel 极限到边界估计的完整接口，所以在三次比较中仍标为“报告声称完成”。

报告的抽象抵消例子也值得保留：它构造一个内部正规收敛级数，使每个有限部分和都有同一个首阶平方根奇性、后续项越来越光滑，但无限和恒为零。这不是 Ising 反例；它说明“所有有限截断都有奇点”仍不足以决定无限和。
