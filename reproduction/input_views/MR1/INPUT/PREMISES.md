# 前提边界

本任务不要求重新从 Gibbs 测度公理推导 Ising 模型。允许以下外部文献输入，但不允许把候选新估计作为公理。

| ID | 允许输入 | 必须尊重的范围 |
|---|---|---|
| E1 | 附带 TW2014v1 Appendix A 所引用的精确低温两点关联函数/Fredholm 展开 | 可以按文献前提接受其关联函数身份。角测度变换、辅助留数、格点求和、onsite/offsite 对应及本包 \(T_N\) 的归一化仍须在 I1 对照核验；不能任选印刷前因子。 |
| E2 | 低温自发磁化的精确式 \(\mathcal M^2=(1-s^{-4})^{1/4}\)，分支由实 s>1 决定 | 局部解析与非零性须在实际使用点检查。 |
| E3 | TW2014v1 固定偶数粒子阶、非 Nickel 点的光滑性结论 | 使用前写出原定理假设。它没有直接给出 Nickel 点补集控制、随 N 一致的界或完整无限和不抵消。 |

Boukraa 等 2008 的精确角积分表示可作独立归一化对照；若作为输入，给出实际公式位置和变量对应。其讨论的自然边界及实验性论据不得升格成已知定理。

PDF 为文献内容的权威版本。附带文本是机械提取，可能损坏上下标和公式，不是另一项独立证据。文献中援引更早来源不等于允许联网补材料；需要但无法从当前输入或标准数学恢复的非标准前提，应明确列为额外假设。

标准复分析、实变量积分与 coarea、线性代数、代数数论等可以引用标准定理。必须给出足以核查适用性的精确陈述；新领域专用的统一估计、无限尾项控制、首项不抵消、给定点族的具体算术性质不属于可免证的一般知识。

所有“proved”均是相对于明确列出的 E1–E3（实际使用的子集）及一般数学背景而言。若用了其他未证专用前提，给它独立 ID，写入 `additional_assumptions`，并把受影响结果记为 `conditional`。

特别地：I3 可以暂缓，却不能在最终全链中无声地假定；I4–I5 也不得通过假定与 TAIL 同强或更强的引理来获得“已重建”。
