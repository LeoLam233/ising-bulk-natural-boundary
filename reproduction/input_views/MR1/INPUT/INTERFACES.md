# I1–I6：证明义务及接合

这些是本实验的编号，不对应任何外部论文的定理编号。每个节点必须引用本次输出中的可定位证据；没有证据的位置明确留空缺口，不能引用本包蓝图代替证明。

| 节点 | 所需产物 | 接口限制 |
|---|---|---|
| I1 | 完整体对象、BULK 归一化、R0 留数、外部单值全纯性及正规收敛 | 不偷换 onsite/offsite、对角/完整、固定阶/无限和；在外部紧集独立给出可求和控制。 |
| I2 | 固定点族的首次阶、唯一性、稠密性、端点非单位根及指数分离 | 有限枚举是诊断，不能替代对全部允许素数的论证。 |
| I3 | 完整 \(T_{N_0}\) 的 \(k\) 阶导数为 \(2L_\beta\varepsilon^{-1/2}+o(\varepsilon^{-1/2})\)，\(L_\beta\ne0\)；较低导数及所有较低粒子阶有界 | 两图表复相位/重数、局部到完整积分的拼接、补集有界及积分顺序都要处理。首项公式只是待证目标。 |
| I4 | 合法且精确的轮廓分解、参数盘、固定实域任意 j≤k 微分、全部通量 | 对实际权重和支撑建立等式；不能只给一个无权重形式积分。 |
| I5 | 完整 TAIL | T1–T6 及区域覆盖均有证据，所有 N 窗口、全部 j≤k、常数选择无循环。 |
| I6 | BULK 的 Leibniz 组合及自然边界 | 首尾使用同一对象、点族、分支、导数和常数范围。I3 或 I5 未闭合时，只能给条件推论。 |

依赖关系：I1→I2；I1+I2→I3；I1→I4；I2+I4→I5；I1+I2+I3+I5→I6。

## 首项若在本次继续重建

候选局部坐标来自两个交换 \(\alpha,\beta\) 的下半平面等角图表。需要证明只有它们贡献所需首阶，并核实两个复系数相加。可考虑固定的 y 权重先局部化，再完整执行 x 留数；在分母已分离的边缘处理平均角截断，形状截断固定，随后变形平均角线段。非全纯实截断不可直接作复角解析延拓。

候选形状缩放是 \(t=\sqrt\varepsilon\,\tau\)，均值先作留数，之后再处理形状积分的主导收敛。不能仅由局部 Taylor 首项宣称完整振幅非零。对补集须自行构造有限覆盖及分离方向的分部积分估计；s* 本身是 Nickel 点，E3 不能直接替代这一步。

## 结论接口

若 I3 与 I5 真正成立，需独立核查全部低阶 Leibniz 项是否足够小，并导出
\[
\mathcal X^{(k)}(s_\varepsilon)
=4\mathcal M^2(s_*)L_\beta\varepsilon^{-1/2}+o(\varepsilon^{-1/2}).
\]
再处理局部延拓矛盾、点族稠密性、偶性和共轭性，以及轴点的邻域。每个点可用不同有限 k；不得额外假设在全部稠密点上的统一振幅下界。

本次主评估 I4–I5；不要求为追求全链标签压缩尚未完成的 I3。只证明“假设 I3/I5 则结论”的逻辑不能把 I6 记为完整自然边界已证。
