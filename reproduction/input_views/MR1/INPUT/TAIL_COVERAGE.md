## 粒子窗和电流窗

令 H=log(1/ε)，\(0<\alpha_0<1/[2(k+2)]\)，\(\lambda_*=\varepsilon^{\alpha_0}\)。所有 N 都是偶数且 N>N0。

- 中间阶：\(N<D\sqrt H\)。
- 较高阶：\(D\sqrt H\le N<C_H(H+1)^2\)。
- 超高阶：\(N\ge C_H(H+1)^2\)，直接估计原始完整积分。
- 超高阶以下的电流分为 \([0,\lambda_*]\) 和 \([\lambda_*,1]\)，该分割在求导后执行。

端点重叠或缺口必须在实际定义里解决；写清有限 ε 下的空窗、取整和固定低阶如何处理。

## 可达成 TAIL 的候选预算

以下都是需要独立推导的充分界，可以用真正足够的其他界替代。对超高阶以下定义已求导并角积分的电流
\[
\mathcal J_{N,j}(\lambda)=-2i\tau\sum_q\int(\partial_{\theta_q}\psi)
\partial_s^jU_{\lambda,s}|_{s=s_\varepsilon},
\quad B_{N,j}=|K_N^{(j)}|+\left|\int_0^{\lambda_*}\mathcal J_{N,j}(\lambda)d\lambda\right|.
\]

\[
\begin{aligned}
\text{F: }&\sum_{N<C_H(H+1)^2}|F_N^{(j)}|\le\exp(C_j\log^2(H+2));\\
\text{大电流: }&\sum_{N<C_H(H+1)^2}\int_{\lambda_*}^1|\mathcal J_{N,j}(\lambda)|d\lambda
\le C_j\lambda_*^{-j-2};\\
\text{较高阶: }&B_{N,j}\le C_j^N\varepsilon^{-j-2}e^{-\kappa N^2};\\
\text{中间阶: }&B_{N,j}\le\exp(C_jN\log(N+1))(H+N)^{C_j};\\
\text{超高阶: }&|T_N^{(j)}|\le C_j\varepsilon^{-j-2}
\left(\frac{C(H+1)}{\sqrt N}\right)^N.
\end{aligned}
\tag{B1--B5}
\]

大电流若获得更强的 \(C_j\lambda_*^{-j-1}\) 可直接使用；若仅证明绝对值在 λ 积分外的足够界，也须清楚区分。所有求和均限制偶数 N>N0。

在共同 κ>0 后选择 \(\kappa D^2>k+2\)，并核验所有窗口相对于 \(\varepsilon^{-1/2}=e^{H/2}\) 的增长。尾项绝对值是 \(|\partial_s^jT_N|\)，不要求把原始全积分先统一取绝对值再微分；但每次分部积分、轮廓变形和改变积分顺序都必须有合法理由。

## 必须自行攻击的边缘配置

两分支、端点及互逆角；p 或 m 的过渡支撑；命名选择权重趋零；\(P\) 的耦合；允许圆盘的所有复方向；N=N0+2 和 j=k；部分碰撞同时趋于全碰撞；均值正负与跨符号；周期标签接缝；高阶导数击中已经生成的场/系数；相位覆盖数；指数尺度的有限低阶包含。

这些检查服务于连续证明。是否运行数值诊断由你决定；如运行，提供源码、参数、实际输出并声明其证明边界。
