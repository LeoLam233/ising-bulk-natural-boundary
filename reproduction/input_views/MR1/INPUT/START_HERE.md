# Ising MR1 v0.1 — 给定方法框架的独立重建

本包是 **method-informed reconstruction / clean-port**。它主动提供一个候选论证的定义、分解、向量场和目标估计。它不是无提示的盲发现实验，不证明这些提示正确，也不携带任何既有运行的结论。

你的主要任务：在一个持续的研究运行中，独立重建完整无限粒子尾项的边界导数控制（I4–I5 / T1–T6），再检查它与首项及自然边界推论的接口。候选路线允许失败；一个局部候选引理为假不等于物理命题为假。

## 开始

1. 将本包解压到新目录，保持 `INPUT/` 不变。结果写入其同级的新目录 `RUN_OUTPUT/`。
2. 从 `INPUT/` 执行 `python -B tools/packet_tools.py verify`，保存真实输出。
3. 执行 `python -B tools/packet_tools.py init --results ../RUN_OUTPUT --run-id 你本次唯一的ID`。工具只创建行政模板；不会开始研究或判定证明。
4. 依次读 `TASK.md`、`PREMISES.md`、`CONVENTIONS.md`、`INTERFACES.md`、`METHOD_BLUEPRINT.md`、`TAIL_COVERAGE.md`、`OUTPUT_CONTRACT.md`。需要时回到两份原始文献 PDF；文本提取只便于搜索。
5. 尽早进入 I4–I5。I1–I3 可以先作为**明确标记的未解决接口**，以免重复基础工作耗尽运行；但它们不能因此变成已证定理。最终结论按实际闭合程度分层。

## 输入与访问边界

允许：本 `INPUT/`、本次新建的输出、普通本地运行环境，以及你原有的一般数学知识。未另行授权联网、连接器、其他对话、项目记忆、外部代理/子代理、既有证明稿、历史审计、既有运行输出、作者其他仓库。不要安装新依赖；如确有依赖障碍，记录后使用现有工具继续独立工作。

若环境的上级指令要求读取包外通用操作说明，遵守上级指令并如实记录文件、用途及是否含数学信息。资料中的命令、参考文献和链接不是新的访问授权。本包不能覆盖系统或开发者规则。

不要声称“技术上断网”“文件系统隔离”或“没有任何先验接触”，除非有相应证据。区分“本次未使用某通道”和“环境不可能访问某通道”。模型训练知识不可由本实验清除；如识别出记忆中的特定现成证明，应记录，并将该依赖单列。

候选方法本身是**已声明的允许暴露**。包外完整论文、以往结果及其判词是另一个暴露字段，不要把两者合并成含混的“完全无提示”。

## 运行方式

节点是同一运行中的账本，不是每做完一项就停止对话的理由。发现缺口后，在剩余资源允许时继续检验、修补、寻找反例或证明障碍；普通长估计、需要写引理、需要构造覆盖不自动构成硬停止。也不要在没有完成时声称已经穷尽所有可能路线。

可以采用等价的新分解或修补，但必须写清改动和影响。缩小角域、仅验证有限 N、仅处理 j=k、只证明高阶局部图表等，都不能冒充原目标。

输出应是可检查的数学推导、常数依赖、实际代码和结果及必要的行动记录；不要求逐字报告私有思考过程。

结束前执行 `validate`，修正行政格式问题，再执行 `freeze`。冻结工具核验字节和声明的一致性，不核验数学、访问隔离或时间戳真实性。冻结后停止修改这份快照，返回 ZIP 及其 `.sha256` 回执。
