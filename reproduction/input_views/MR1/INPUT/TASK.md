# 固定任务与成功标准

研究无限、各向同性、铁磁平方格点 Ising 模型的低温完整体磁化率。取实温度侧的正场极限纯相，令

\[
s=\sinh(2\beta J),\qquad
\mathcal X(s)=\beta^{-1}\chi(s)
=\sum_{(m,n)\in\mathbb Z^2}(\langle\sigma_{00}\sigma_{mn}\rangle_+-\mathcal M^2).
\]

起点是实数 s>1 的解析芽，\(\mathcal M^2(s)=(1-s^{-4})^{1/4}\) 的分支在无穷远趋于 1。包含原点项；不得替换为对角磁化率、有限体积或有限粒子截断。

## 本阶段主目标

对 `CONVENTIONS.md` 中**每个固定的允许点**，以同一归一化的 \(T_N\)、同一 \(N_0,k\)，独立证明

\[
\forall j\in\{0,\ldots,k\},\qquad
\lim_{\varepsilon\downarrow0}\varepsilon^{1/2}
\sum_{\substack{N>N_0\\N\text{ even}}}|\partial_s^jT_N((1+\varepsilon)s_*)|=0.
\tag{TAIL}
\]

这是完整粒子尾项、完整积分域上的绝对求和。一个固定 N 的界、有限个 N 的数值测试、局部鞍点附近的高阶尾项都不是 TAIL。

## 全链目标与单独计分

同时记录下列两个全链断言的状态：

1. 上述芽在 \(|s|>1\) 有单值全纯延拓，偶数粒子级数及固定阶导数在外部紧集上正规收敛。
2. 单位圆是该芽的自然边界：每个 \(|s_0|=1\) 的邻域都不存在与外部芽相容的全纯延拓。

本阶段优先重建 I4–I5；完成 TAIL 而 I3 首项仍未独立闭合时，可以报告 `CLAIMED_TAIL_PROOF`，必须把完整自然边界保留为未解决或条件结论。不能为了获得全链标签而继承候选首项公式。

`CLAIMED_FULL_PROOF` 要求 I1–I6 全部闭合。`CLAIMED_DISPROOF` 要有上述全链断言的实际否定证据。候选路线中的错误、TAIL 这个充分条件的失败、未能证明，均不能单独构成自然边界命题的反证。
