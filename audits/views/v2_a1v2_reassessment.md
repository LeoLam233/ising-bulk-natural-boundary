## 2. 新增的独立计算：从原始四重轮廓出发

为了避免只重跑同一套内根/留数实现，本轮另写 `independent_checks.py`，直接计算 N=2 的原始四重轮廓积分，不调用内根选择或留数降维代码。

设 X=x₁x₂、Y=y₁y₂，定义

\[
H_x=\frac{x_1-x_2}{(1-X)^2},\qquad
H_y=\frac{y_1-y_2}{(1-Y)^2},\qquad
D_{ab}=s+s^{-1}-\frac{x_a+x_a^{-1}}2-\frac{y_b+y_b^{-1}}2.
\]

归一化角测度下，原始密度化为

\[
\frac12 H_x H_y\frac{X+Y}{D_{11}D_{22}}.
\]

采用不同的 x、y 半径 0.73、0.84 和不同网格偏移。四维梯形求和通过矩阵乘法收缩计算，不实际分配四维数组。

| 每角网格数 | 原始四重积分与留数降维值之差 |
|---:|---:|
| 24 | 5.10835×10⁻⁶ |
| 48 | 1.18622×10⁻⁹ |
| 96 | 6.39738×10⁻¹⁷ |
| 192 | 8.15545×10⁻¹⁹ |

最终得到 T₂≈0.0028908677473843654。这个独立表示检查进一步支持轮廓归一化与降维的一致性。它仍是浮点检查，且验证的是原始轮廓公式与其降维式的一致性，不单独证明原始公式与物理量的全部一般阶对应。

外部约定对照使用 [Tracy–Widom Appendix A](https://arxiv.org/pdf/1403.3966v1) 与 [Boukraa 等的式 (4)–(9)](https://arxiv.org/pdf/0808.0763)。后者的约束角表示在 N=2 时成为脚本中的一维积分。固定阶输入不能代替无限尾和结论。

## 3. 附录 C：真实错误，结论可以保留

定位：v2 独立 TEX 第 1605–1607 行附近。

固定 0<r<1，Y 是 N 个模长为 r 的变量之积，故

\[
|Y^{-1}|=r^{-N}.
\]

因此将 inverse products 说成由与 N 无关的常数控制，逐字错误。这项批评成立，不应为了维护论文而否认。

本轮用色散方程直接给出需要的下界。若固定外部紧邻域上 |W|≤M、内根 |z|≤q<1，则

\[
z+z^{-1}=2W
\quad\Longrightarrow\quad
|z|^{-1}=|2W-z|\le2M+q.
\]

所以 m=(2M+q)⁻¹ 是统一正下界，进而

\[
|Z^{-1}+Y^{-1}|\le m^{-N}+r^{-N}\le2C_1^N.
\]

两 Pfaffian 的 Hadamard 界相乘给 C₂ᴺNᴺᐟ²，再除 N!：

\[
|T_N|\le C_0\frac{C_3^N N^{N/2}}{N!}
\le C_0\left(\frac{eC_3}{\sqrt N}\right)^N.
\]

额外逆乘积增长可吸收到 C₃ 中。稍大紧邻域上的同一估计再配合 Cauchy，仍给每个固定阶导数的局部正常收敛。

结论：原句 CLOSED-FAIL；修正后的正常收敛结论 CLOSED-PASS。修正不改变模型、边界点族、导数阶数或主定理目标。可直接采用的英文 TEX 见同目录 `ising_v2_appendix_C_erratum_20260925.md`。

## 4. 本轮核查的三个尾项接口

### 4.1 固定阶求导不需要保留固定比例的全部配对

令 q′<1、a=−log q′>0，b=log(1+η)<a/4。同组对数 S≥N²/6−N/2，跨组 X≤N²/3。至多 j 个配对被求导后，未改变部分满足

\[
(q')^{S-j}(1+\eta)^X
\le(q')^{-j}\exp\left(-\frac a{12}N^2+\frac a2N\right).
\]

若 S−j<0，这仍是宽松上界，不要求实际剩余配对数为负。被改变因子的固定阶有界性另按稿件的正则坐标估计处理。

关键量词是先固定点与 j≤k，再让 N、ε 变化。(q′)⁻ʲ 是允许的固定常数。N₀=22、j=241、N=24 的有限窗口不能据此否定二次指数估计。这一计算验证的是计数接口；同组严格界在实际复参数域上的成立，仍须靠对应解析引理。

### 4.2 五类高阶递推的次数确实相容

在稿件所用正则坐标中，选中差值 δ=φₚ−φ_q 在固定 φ 的 s 导数下不变；残余场至多有一个 δ 极点，散度至多两个。于是五类操作对两种次数的最大增量是：

| 操作 | m+\|μ\|+\|ν\| | ℓ+\|μ\|+\|ν\| |
|---|---:|---:|
| 固定 φ 的参数导数作用于系数 | 0 | 0 |
| B 作用于系数，或乘散度 | 2 | 0 |
| B 作用于分子 | 2 | 1 |
| 参数导数作用于分子 | 0 | 1 |
| V 作用于实域权重 | 2 | 1 |

这给出一般固定 j 的次数归纳，而不需要把 241 阶逐项展开。该归纳本身的条件包括正则坐标中系数的有界性、核冻结和穿孔通量消失；不能把次数归纳说成它同时独立证明了所有这些几何条件。

对稿件声称的通量幂次，最差 j=k、N=N₀+2 时，N²−2j−3=4N₀+3>0，窗口底端相容。

### 4.3 e^(CN³) 的吸收可以给出显式充分条件

设 n=N₀+2、k=N₀²/2−1，

\[
L=N^2-2j-4,\qquad
d_0=\frac{4N_0+2}{(N_0+2)^2}>0.
\]

对全部 N≥n、j≤k，有 L≥d₀N²。这里使用

\[
\frac{L}{N^2}\ge1-\frac{N_0^2+2}{N^2},
\]

其右端随 N 增加。

若近碰撞转换系数已证明为 e^(CN³)，且 C 不依赖随后选择的 B，那么取

\[
B\ge\frac{C+1}{d_0}+\frac{\log2}{n}
\]

并同时保留稿件已有的 B>A+5 等要求（对各充分下界取最大值），就有

\[
e^{CN^3}(2e^{-BN})^L\le e^{-N^3}.
\]

证明是先用 log2−BN≤−(B−log2/n)N，再用 L≥d₀N²。N₀=22 时 d₀=5/32。这清楚显示 B 可以依赖固定 N₀、k，而无需对所有选点统一。余下 e^{C_jN log(N+1)} 的代价可由负三次项吸收，有限小阶归入常数。

因此，报告关于“存在支付 e^(CN³) 代价的来源”的接口论证有内容；不能仅凭该正三次项就判定失败。不过，上游原始积分确实满足所列 e^(CN³) 界、且 C 不依赖 B，仍属于相应扇区推导的内容。
