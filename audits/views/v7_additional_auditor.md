# 审计结论

**这份 v7 稿件目前没有被我击穿。**我没有找到能够直接否定核心估计 (1.1) 或 (1.2) 的可复现反例，也没有找到一个已经可以明确判定为致命的代数错误、漏项或量词倒置。

但这个结论有明确的限度：**局部等式、留数符号、两图振幅、微分递推和关键指数，我进行了独立复算；涉及全部角区、复参数圆盘和任意固定阶有限导数的统一估计，我没有将其提升为“已完成完全独立证明”的认证结论。**尤其不能把“本轮未发现反例”当作定理成立的新前提。

我确实找到了一处需要严格限定语义的收缩表述：**“一个端点与一个紧致点配对时仍严格收缩”不能无条件成立。**下面给出精确反例。不过，该反例攻击的是一个过强的读法；论文真正需要的“同组严格收缩、跨组允许接近一”的计数，并没有因此被推翻。

以下是具体审计。

---

## 一、先确定什么才算真正击穿证明

这篇论文的结论不是单靠稠密 Nickel 点或某个固定粒子数的奇性得出的。它需要同时成立：

\[
T_{N_0}^{(k)}(s_\varepsilon)
=
2L_\beta\varepsilon^{-1/2}
+
o(\varepsilon^{-1/2}),
\qquad L_\beta\neq0,
\]

以及对**每一个** \(0\le j\le k\)，

\[
\sum_{\substack{N>N_0\\N\ \mathrm{even}}}
\left|T_N^{(j)}(s_\varepsilon)\right|
=
o(\varepsilon^{-1/2}).
\]

论文明确把二者分开，且没有把固定阶光滑性定理冒充无穷和不相消定理。[interface reference omitted]

因此，真正有效的攻击应当是以下类型：找出首项系数其实为零或两图相消；找出尾项估计遗漏的区域或导数项；找出复轮廓越过奇点；找出没有被吸收的 \(\varepsilon^{-c}\)、\(e^{cN^3}\) 或碰撞极点；或者证明某组所谓统一常数实际上必须随 \(N\) 或 \(\varepsilon\) 恶化。

反过来，指出“固定项奇性不能自动推出无穷和奇性”，**本身已经不足以反驳这份稿件**。必须进一步攻击它专门为此提出的第 5—8 节。

---

## 二、一个可以写出精确反例的地方：端点配对并不总是严格收缩

引理 7.2 在讨论紧致分组时，有一句“一个端点与一个紧致点配对时严格性仍保持”。这句话必须限定为有关的**同组配对**；若理解成任意端点与任意紧致点，则为假。其上下文随后实际采用的是三组计数。[interface reference omitted]

令

\[
S_*=2\cos\theta_*\in(0,2),\qquad
\xi=e^{-i\theta_B},\qquad
\cos\theta_B=S_*-1.
\]

在边界极限 \(s=s_*\)、\(|y|=1\) 上，取第一个点

\[
y_1=1,\qquad z_1=\xi.
\]

再取一个严格位于左侧紧致区的点

\[
y_2=e^{i\theta},\qquad -\pi<\theta<-\theta_B.
\]

这时

\[
W(y_2;s_*)=S_*-\cos\theta>1,
\]

所以内根 \(z_2=t\) 是一个实数，满足 \(0<t<1\)。于是完整配对因子为

\[
P_{12}
=
\frac{\xi-t}{1-\xi t}
\frac{1-y_2}{1-y_2}
=
\frac{\xi-t}{1-\xi t}.
\]

因为 \(|\xi|=1\)、\(t\in\mathbb R\)，

\[
|\xi-t|^2
=
1+t^2-2t\Re\xi
=
|1-\xi t|^2,
\]

从而

\[
\boxed{|P_{12}|=1.}
\]

这不是只有精确分支点才出现的孤立等号，而是一整族端点—左紧致区配对。类似地，\(y_1=-1\) 与右侧紧致区的点也可产生模长一的配对。这里使用的正是论文的完整配对表达式。[interface reference omitted]

**为什么这还没有击穿引理 7.2？**

因为上述两点属于不同组。论文实际只需要同组配对有 \(q<1\)，跨组配对允许 \(1+\eta\)。若三组占据数为 \(n_B,n_L,n_R\)，则

\[
\sum_{\nu=B,L,R}\binom{n_\nu}{2}
\ge \frac{N^2}{6}-\frac N2,
\]

仍能用大量同组配对产生二次指数抑制。

**审计判断：这是一条真实的“禁止过强推论”，不是已经得到的尾界反例。**相关文字应始终按“同组”理解；任何后续推导一旦暗中使用“所有配对均有统一 \(q<1\)”，就会被上面的反例直接推翻。

## 三、归一化、算术与外部输入：这些攻击未成功

### 1. 是否证明了错误的可观测量？

我核对了低温、全体格点求和、连通关联和归一化的对应关系。Tracy–Widom 的原文确实把问题写成低温 susceptibility 的偶数阶展开；其固定阶结论是非 Nickel 点处的 \(C^\infty\) 延拓，并没有给出无穷尾项不相消结论。[interface reference omitted]

归一化最危险的是少算一组 \(2\pi i\)。从每个角度的

\[
\frac{d\theta}{2\pi}=\frac{dx}{2\pi i x}
\]

开始，每个辅助留数又带入一次 \(dy/(2\pi i)\)，确实产生 \(2N\) 个归一化测度。原始附录的角积分公式支持这个计数；不能仅凭其主文印刷前因子来决定物理振幅。[interface reference omitted]

Boukraa 等人的独立角积分也具有 \(N-1\) 个角测度、粒子积因子和平方配对因子，与稿件附录 F 的变量对应一致。[interface reference omitted]

**未找到把 bulk 偷换成 diagonal、把非原点项误当全格点项，或漏掉整体因子二的明确错误。**稿件给出的关系是

\[
C_N^{\mathrm{std}}=f_{00}^{(N)}+2T_N,
\]

而不是把二者直接认作同一个粒子项。[interface reference omitted]

### 2. 是否存在更低的偶数 Nickel 阶？

设 \(d=(p-1)/2\)。论文中

\[
\operatorname{Tr}_{E/\mathbb Q}(2c)=-1
\]

与 \(2c>0\) 结合，确实排除了 \(2c\in\mathbb Q\)。若偶数 \(n<2p\)，则 \(p\nmid n\)；同一个 Nickel 表示会使 \(c\) 落入

\[
\mathbb Q(\zeta_p)\cap\mathbb Q(\zeta_n)=\mathbb Q,
\]

产生矛盾。

我也检查了这里的偶数限制：它不可省略，因为 \(p\) 本身是奇数；但稿件始终只讨论偶数粒子数，没有漏掉一个介于 \(p\) 与 \(2p\) 之间的偶数倍数。[interface reference omitted]

### 3. 首阶的余弦对是否真的唯一？

这里最容易出错的是“稀疏关系”的计数。

两个余弦对相等，至多涉及四个非恒定位置 \(u_j\)。而 \(p\ge11\) 保证 \(d\ge5\)，所以至少存在一个没有使用的 \(u_j\) 位置。唯一的有理关系

\[
1+\sum_{j=1}^d u_j=0
\]

若以非零倍数出现，每个位置的系数都必须相同；未使用位置的零系数迫使这个倍数为零。因此不能产生第二个不同的余弦对。

这一步没有发现遗漏的负号组合或 \(\pm1\) 端点组合。[interface reference omitted]

### 4. 分支相位是否可能是单位根，使微核失去非共振间隙？

对

\[
w=\xi+\xi^{-1}=u_a+u_b-2,
\]

稿件算得

\[
\operatorname{Tr}_E(w)=-2d-2.
\]

若 \(\xi\) 是单位根，\(w\) 的全部共轭都位于 \([-2,2]\)，迹不可能小于 \(-2d\)。这个矛盾成立。

随后 resultant 给出的指数下界

\[
|1-\xi^N|\ge e^{-AN}
\]

也足够；这里不需要多项式级的丢番图下界。[interface reference omitted]

**算术链条是本轮最不容易攻击的部分之一。**

## 四、首个奇异项：真正危险的地方不是形式展开，而是积分顺序与拼接

### 1. 把光滑截断搬进复轮廓，是否非法？

这种攻击通常有效：光滑实角权重没有理由能作全纯延拓，不能随意带着它移动复轮廓。

v7 的处理是先在双轮廓中放入仅依赖 \(y\)-角度的权重，保持所有 \(x\)-积分不加权；做完 \(x\)-留数后，再把均值截断替换成硬区间，只移动均值变量，形状截断不动。替换差支撑在两个全局分母都分离的边缘区。这个顺序确实避开了上述非法操作。[interface reference omitted]

### 2. 是否在选中的 Nickel 点错误调用了“非 Nickel 光滑性”？

若直接说“余项由 Tracy–Widom 定理光滑”，这里会有循环，因为当前点恰好是 Nickel 点。

稿件没有这么做。引理 4.3 重新检查局部奇异因子梯度：含配对向量的非负零组合被排除；两个全局乘积向量同时出现时，才逼出全等配置；单个乘积向量的情形则被 \(\xi\) 非单位根排除。然后对避开两张坏图的紧致支撑作有限覆盖和分部积分。[interface reference omitted]

这个论证仍值得逐图复核，但**不能用“选中点是 Nickel 点”一句话把它反驳掉**，因为它使用的是局部梯度机制，不是直接套全局非 Nickel 假设。

### 3. 均值留数的符号是否反了？

在

\[
Y=r^N e^{iv}
\]

中，\(Y=1\) 的局部极点位于

\[
v=-iNc_0\varepsilon.
\]

向下闭合是顺时针，贡献 \(-2\pi i\)；同时

\[
\partial_v(1-Y)=-i
\]

在极点成立。所以因子为

\[
\frac{-2\pi i}{-i}=+2\pi.
\]

**正号成立。**这不是可以随意吸收进“某个非零常数”的细节，因为两图相消审计需要跟踪相对相位。[interface reference omitted]

### 4. 联合绝对值支配收敛，确实会失败

这是我认为首项部分最重要的攻击。

齐次模型含有

\[
\frac{1}
{(Nc_0-iw)(NA_0+ibw-idR^2)^{k+1}}.
\]

在移动脊线

\[
w\approx \frac db R^2
\]

附近，第二个分母保持常数量级，而第一个分母只有 \(R^2\) 量级。因此，对这一固定宽度的 \(w\)-带取绝对值积分，至少得到 \(R^{-2}\) 量级。

乘上形状径向分子 \(R^{N^2-2}\)，尾部表现为

\[
R^{N^2-4},
\]

不可积。

所以，**任何把未积分的均值—形状联合绝对值当成全空间控制函数的证明，都会在这里失败。**

但 v7 先做实际均值留数，之后的径向尾部才变成

\[
R^{N^2-2}R^{-2(k+1)}=R^{-2}.
\]

附录 B 明确排除了前一种做法。[interface reference omitted]

### 5. \(\varepsilon^{-1/2}\) 的次数是否数错？

均值留数后，形状维数是 \(N-1\)，Vandermonde 平方次数是 \(N(N-1)\)。第 \(j\) 阶导数的径向幂为

\[
N(N-1)+(N-2)-2(j+1)
=
N^2-2j-4.
\]

于是 \(j=k=N^2/2-1\) 时为 \(-2\)，对应 \(\varepsilon^{-1/2}\)；而 \(j=k-1\) 时为 \(0\)，仍可积。

这个“第一不有界导数”的次数与稿件一致，没有发现差一阶错误。[interface reference omitted]

### 6. 两张图是否可能大小相等、相位相反？

我重新检查了配对负号、单体测度中的 \(i^{-N}\)、根的乘积和交换后的正弦幂。

单体与配对的组合相位满足

\[
i^{-N}(-1)^{N(N-1)/2}=1
\qquad(N\ \text{为偶数}).
\]

交换 \(\alpha,\beta\) 后，振幅中正弦幂的总指数为

\[
-N^2-k+\frac12+3a_0=0,
\qquad a_0=\frac{N^2-1}{2}.
\]

因此交换不会改变振幅大小；两边也使用同一支

\[
(-id)^{-a_0}.
\]

**没有发现 \(L_\alpha=-L_\beta\) 的符号机制。**稿件的 \(L_\alpha=L_\beta\) 在这一复算中成立。[interface reference omitted]

外部综述的振幅公式仍涉及角度符号和幂支约定，不能自动充当内部振幅的独立认证。综述印出的幂确实包含这一相位敏感性；稿件附录 F 对正角度与逆角度的比较保留了区别。[interface reference omitted] [interface reference omitted]

## 五、加权轮廓变形：漏掉 Stokes 项的攻击在 v7 上不成立

### 1. 加权积分一般不具备轮廓不变性

对

\[
\int \psi\,U_{\lambda,s},
\]

即使原始全纯形式闭合，也不能直接断言它与 \(\lambda\) 无关。权重的角导数会产生修正项。

稿件实际写出了

\[
T_N=F_N+K_N+S_N,
\]

并保留了

\[
S_N=-2i\tau\int_0^1
\sum_q\int(\partial_{\theta_q}\psi)\,U_{\lambda,s}\,d\lambda.
\]

我复算了这个系数。命名指标 \(q\) 位于平台上，角 Jacobian 的第 \(q\) 行、列在非对角位置均为零，且

\[
d_q=i,\qquad h_q=-2\tau.
\]

因此相应角速度为

\[
h_q/d_q=2i\tau,
\]

再由分部积分产生前面的负号。**没有找到符号或遗漏修正项的问题。**[interface reference omitted]

### 2. 占据数耦合是否破坏 Jacobian 计算？

矩阵是“对角矩阵加秩一项”。关键不在于忽略秩一项，而在于

\[
m_i p_i'=0
\]

使 determinant lemma 中的修正项恰好消失。命名 \(q\) 的平台条件又保证替换列计算不带来额外项。

这是一个必须在**全部权重导数支撑上**保持的条件。稿件把 \(p=1\)、\(m=0\) 要求放在开邻域，而不是仅要求某个点上成立，因此当前有限 jet 支撑机制没有被这一攻击击穿。[interface reference omitted] [interface reference omitted]

### 3. 扩大的 Cauchy 圆盘是否暗中穿越奇点？

这里不能笼统说“轮廓合法，因此可在 \(c/N\) 圆盘上用 Cauchy”。原始轮廓一般只有 \(c\varepsilon\) 圆盘。

稿件区分了三种尺度：

| 对象 | 圆盘尺度 | 必须保护的机制 |
|---|---:|---|
| 原始轮廓及高阶 \(K\)/小电流部分 | \(c\varepsilon\) | 原始径向耗散 |
| 最终选择轮廓 \(F_N\) | \(c/N\) | 固定上侧锚点与下分支位移 |
| 大 \(\lambda\) 电流 | \(c\lambda_*/N^2\) | 大小为 \(\lambda\) 的锚点耗散 |

尤其对大电流，紧致根允许膨胀到单位圆外；真正用到的是

\[
|Z|
\le
\exp(-c_q\lambda+CN\delta_s).
\]

取 \(\delta_s=c\lambda_*/N^2\)，且 \(\lambda\ge\lambda_*\)，确实可以让后项被前项吸收。稿件没有错误地坚持“所有紧致根仍留在单位圆内”。[interface reference omitted] [interface reference omitted]

**这一部分仍是优先认证对象，但我没有找到一个具体圆盘内的穿越反例。**

### 4. \(F_N\) 中是否遗失了 \(e^{CM\sqrt N}\)？

若分支—紧致配对的 \(1+C/\sqrt N\) 膨胀被直接丢弃，证明会出问题。

稿件保留了

\[
\exp(CN+CM\sqrt N-aM^2)
\]

并使用

\[
CM\sqrt N
\le
\frac a2M^2+\frac{C^2}{2a}N.
\]

这一步有效，留下 \(C_1^N e^{-a_1M^2}\)。再结合单体代价、Pfaffian minor 和 \(N!\)，得到 \(N^{-N/4}\) 级的余量。

另一个潜在错误是对依赖 \(s\) 的逐点分组积分分别用 Cauchy。v7 没有这样做：它先估计完整 \(F_N\)，再对完整全纯积分用 Cauchy。[interface reference omitted]

## 六、高阶微分：最危险的隐藏极点攻击没有在核心递推中成功

### 1. 不能只验证一阶冻结

所选的最小例子已经有

\[
N_0=22,\qquad k=241.
\]

因此一阶恒等式正确，远远不够。需要检查重复作用时对向量场、散度、旧系数和截断的导数是否全部计入。

对原始全分支图，稿件的向量场确实满足

\[
\sum_iV_i=0,\qquad
\sum_i b_iV_i=\partial_s\sum_i\phi_i.
\]

所以 \(Y,Z\) 被冻结。进入规则分支坐标后，残余场只有两个非零分量，且只有一个选中差分极点。[interface reference omitted]

### 2. 对原 Vandermonde 作对数微分，会直接毁掉“只有选中极点”的说法

例如

\[
\partial_{\phi_p}\log\Delta(\phi)^2
=
2\sum_{\ell\ne p}\frac1{\phi_p-\phi_\ell}
\]

会在每个未选中的碰撞上产生极点。

这是一条很强的攻击，但稿件明确保留未因子化分子 \(N_s\)，不除回原 Vandermonde。于是一次分子导数只修改有限个配对因子，不会把所有未选中碰撞变成分母。[interface reference omitted]

### 3. 两幂损失递推是否漏项？

我按其五种操作重新核对了计数：

| 操作 | 对选中差分极点及次数的影响 |
|---|---|
| 固定 \(\phi\) 的 \(s\)-导数作用于系数 | 不提高差分极点阶 |
| \(B\cdot\nabla_\phi\) 作用于系数 | 至多增加两阶 |
| 乘以 \(\operatorname{div}_\phi B\) | 至多增加两阶 |
| \(B\cdot\nabla_\phi\) 作用于分子 | 一个分子导数加一个极点 |
| 作用于实截断 | 一个截断导数加至多一个极点 |

这与

\[
m+|\mu|+|\nu|\le2j,
\qquad
\ell+|\mu|+|\nu|\le j
\]

一致。特别是旧向量场系数的参数导数没有被排除在递推之外。**核心全分支递推未发现“实际每阶损失三幂”或“损失随 \(N\) 增长”的漏项。**[interface reference omitted]

### 4. 选中对角线与全相等集合的通量不能直接丢掉

有理权重

\[
w_{pq}
=
\frac{(u_p-u_q)^{2M}}
{\sum_{i<\ell}(u_i-u_\ell)^{2M}}
\]

的作用不仅是选一对点，还必须抵消所选场的极点。

稿件给出的选中管道通量幂为

\[
2M+1-2j>0,
\]

全相等球面的充分通量幂为

\[
N^2-2j-3>0.
\]

在最小尾阶 \(N=24,j=241\) 时，后者是 \(91\)，并没有刚好卡在不可积临界上。

这里“先固定 \(\varepsilon,N\)，再去掉穿孔”的次序是正确的；它不要求穿孔通量估计中的常数先对 \(\varepsilon\) 一致。[interface reference omitted]

### 5. 混合图是否把耦合占据数误当常数？

这是另一个很容易藏错误的位置。

稿件并非在所有积分中无条件把 \(P\) 当常数。它在混合小电流图中，选取位于平台上的命名上侧指标和真分支指标，使场满足

\[
V\cdot\nabla P=0,\qquad
V\cdot\nabla\sum_i m_i=0.
\]

同时，选中分支残余速度中的分母是

\[
1-\frac{b_q}{b_j},
\]

而 \(1/b_j\) 在规则分支坐标中解析并趋于零。这确实避免了新的分支极点。完整混合测度也保留了耦合 Jacobian，而不只是把若干 \(d\theta_i\) 形式替换掉。[interface reference omitted]

**核心代数没有错；但把全部高阶有限 jet、全部混合支撑与统一配对抑制完整拼起来，仍是本轮保留认证风险的部分之一。**

## 七、指数尺度与 coarea：我重点检查了四种可能致命的偷换

### 1. 把“每个固定 \(N\)”偷换成窗口内统一成立

中间窗口是 \(N\le D\sqrt H\)，其中 \(H=\log(1/\varepsilon)\)。对任意已经固定的 \(C,m,r>0\)，

\[
\log\!\left(\varepsilon^r e^{CN}N^m\right)
\le
-rH+CD\sqrt H+O(\log H)\longrightarrow-\infty.
\]

因此，稿件所需的指数小尺度比较在这个窗口里确实可以统一成立。它没有把该比较延伸到 \(N\asymp H^2\) 的高阶窗口。[interface reference omitted]

### 2. 微核界是否漏掉了正的 \(N^3\) 代价？

微核上界的对数是

\[
\log\left(e^{C_jN^2}b_N^{(N^2-1)/2}\right)
=
-\frac{A+4}{2}N^3
-\frac12N^2\log N
+O_j(N^2).
\]

负的 \(N^3\) 项没有被正代价抵消；v7 也保留了负的 \(N^2\log N\) 项。这个级数可求和。[interface reference omitted]

### 3. \(e^{CN^3}\) 是否被无根据地降格成次指数？

在近全相等区，不能声称 \(e^{CN^3}\) 属于 \(e^{O_j(N\log N)}\)。这会是致命错误。

稿件保留它，并乘上

\[
(2\rho_N)^L,\qquad
\rho_N=e^{-BN},\qquad
L=N^2-2j-4.
\]

合并后

\[
CN^3-BNL
=
(C-B)N^3+B(2j+4)N.
\]

只要 \(C\) 在选择 \(B\) 之前固定，再取 \(B>C\)，大 \(N\) 的三次项就能被吸收。

最需要防止的是循环：若那个 \(C\) 又通过截断导数随 \(B\) 增长，就不能这样选。稿件的处理是把尺度截断导数计入已经扣除的形状幂损失，而把分支坐标转换代价归入由 \(b_N\) 决定的 \(C\)。这一依赖顺序至少在给出的计数机制中是相容的。[interface reference omitted] [interface reference omitted]

### 4. coarea 是否偷偷多赚了一次 \(\rho\) 积分？

正确的剩余幂来自：

\[
\underbrace{N(N-1)}_{\text{碰撞零点}}
+
\underbrace{N-2}_{\text{形状测度}}
-
\underbrace{(2j+1)}_{\text{导数及保守损失}}
-
\underbrace{1}_{\text{coarea Jacobian}}
=
N^2-2j-4.
\]

一旦把 \(\rho\) 换成相位，就不能再把它当独立变量积一次。稿件目前的写法是先用支撑上界控制 \(\rho^L\)，随后积分相位核，没有第二次把同一个 \(\rho\) 积掉。[interface reference omitted] [interface reference omitted]

最小尾阶满足

\[
L\ge4N_0+2,
\]

在 \(N_0=22\) 时为 \(90\)。这给碰撞区留下了明显正余量。

## 八、相位几何：极值选取、负坐标和周期绕行都不能省略

### 1. 在微分之前用最大值、最小值分区，会引入非光滑边界

稿件是在全部微分完成后的绝对值积分中，才选择实际最小值 \(m\) 和最大值 \(M\)。因此没有把 \(\max\)、\(\min\) 的分布导数带入 Lie 递推。

对非负全分支区，相位映射的 Jacobian 为

\[
x'(m)-x'(M).
\]

命名锚点保证 \(M\gtrsim b_N\gg\varepsilon\)。当 \(m\le M/2\) 时用强斜率差；当二者可比时，二者都远大于 \(\varepsilon\)，再用严格凹性。这个分案没有明显遗漏。[interface reference omitted] [interface reference omitted]

### 2. 负分支坐标是否留下一个 \(\varepsilon^{-1/2}\) 单体奇性？

负坐标的衰减与单体测度组合后，稿件使用

\[
\frac{|\phi'(u)|}{|1-Z|}
\lesssim \frac1{|u|+\varepsilon}.
\]

这确实只产生对数，而不是未受控的 \(\varepsilon^{-1/2}\) 因子。较大的负坐标直接提供指数 \(N\) 级的 \(Z\)-间隙；所有负坐标都很小时，锚点必须为正，可用另一个变量积分 \(Y\)-核。[interface reference omitted]

### 3. 全紧致右区的凹性是否可能在耦合后消失？

极限相位满足

\[
g''(\theta)
=
-\frac{S_*(1-\cos\theta\cos g(\theta))}
{\sin^3g(\theta)}<0.
\]

耦合扰动在中间窗口是

\[
N^{C_j}(\varepsilon+\lambda_*)\longrightarrow0.
\]

因此，在固定紧致右区上保持严格凹性是可能的。排列对称性还使全相等点处的一阶形状导数为零，给出

\[
-\partial_\rho G\gtrsim\rho.
\]

稿件也修正了 \(d\) 与 \(\rho\) 的区别：近区只推出

\[
\rho\le\sqrt N\,N^{-K_0},
\]

而不是错误地写成 \(\rho\le N^{-K_0}\)。[interface reference omitted]

### 4. 周期相位是否漏计了 \(N^2\) 个周期盒？

近全相等区的未取模相位长度是 \(O(N)\)，不是 \(O(1)\)。因此两个周期核必须允许

\[
CN^2(H+N)^2
\]

这样的因子。

v7 明确保留了这个周期长度代价；同时把“未取模映射的重数一”与“周期绕行次数”分开。没有发现用单周期估计覆盖长度 \(O(N)\) 相位区间的错误。[interface reference omitted] [interface reference omitted]

## 九、尾项区域覆盖：没有找到一个明显漏掉的第十四区域

我按实际支撑和分割逻辑检查了论文的十三类区域，而不是仅接受附录 G 的目录。

| 区域 | 主要攻击点 | 本轮结果 |

## 十、最终求和与量词：目前没有发现不合法的交换

把各部分写成 \(H=\log(1/\varepsilon)\) 的增长率，目标是小于 \(e^{H/2}\)。

最终选择部分为

\[
e^{O_j((\log H)^2)}=e^{o(H)}.
\]

中间阶全部区域之和为

\[
e^{O_j(\sqrt H\log H)}=e^{o(H)}.
\]

大电流使用的较弱界为

\[
e^{\alpha_0(j+2)H}=o(e^{H/2}),
\]

因为 \(\alpha_0<1/[2(k+2)]\)。

高阶部分为

\[
\exp\!\left((j+2-\kappa D^2)H+O_j(\sqrt H)\right),
\]

而选择 \(\kappa D^2>k+2\) 足以统一覆盖全部 \(j\le k\)。

超高阶部分则有负的 \(H^2\) 指数。**这些求和指数彼此相容。**[interface reference omitted]

另外三种常见错误在这里没有出现：

**没有把移动窗口拿来求导。**粒子数窗口和 \(\lambda_*\) 都是在微分之后引入。

**没有对所有 \(N\) 使用 \(1-r^N\gtrsim N\varepsilon\)。**实际需要的是带饱和的 \(\min(1,N\varepsilon)\) 型间隙。

**没有只估计最高阶尾项。**最终乘积法则需要的全部 \(j\le k\) 都包含在目标中。[interface reference omitted] [interface reference omitted] [interface reference omitted]

若两个核心估计成立，第 9.2 节的结论推导没有明显问题：\(M^2(s_*)\neq0\)，低阶乘积项是小量，稠密的径向导数爆破排除局部全纯延拓。这里不需要对所有素数统一控制导数阶，也不需要把 \(\beta(s)\) 声称为整个外域上的单值函数。[interface reference omitted]

## 十二、仍然不能被“未发现反例”替代的认证工作

剩余风险集中在三个接口，而不是最后的自然边界推论。

**第一是完整配对因子的全支撑统一性。**需要同一组严格常数覆盖分支分辨坐标、端点薄片、全部占据数、命名上侧变量和所声明的复参数圆盘。这里不要求给出常数的具体数值；要求的是统一紧致性与间隙论证能够独立重现。第二节的精确等号族说明，任何不慎加强为“所有配对严格收缩”的简化都会失败。

**第二是混合坐标和全紧致坐标下的完整高阶推广。**全分支的核心递推我没有发现漏洞；但混合图中同时保留权重支撑、耦合 Jacobian、全部旧系数导数和未修改配对收缩，是比验证一阶冻结更强的命题。不能用一阶恒等式或有限数值测试替代它。

**第三是第 6.1 节扩大圆盘上的完整积分全纯性与统一主控。**逐点分组可以依赖 \(s\)，但 Cauchy 必须作用于固定角权重的完整积分；保护根、单体主控、全局乘积间隙和配对估计必须在同一个圆盘上同时成立。v7 的写法意识到了这些要求，我没有给出反例，但这仍值得单独作逐引理认证。

**最终裁决是：v7 未被本轮敌对性审计击穿；不能据此签发“证明正确”的证书，也没有足够根据宣称这份证明已经失败。**目前最有价值的反驳方向，是在上述三个统一接口中给出具体参数族、遗漏项或失败的不等式，而不是重复那些当前版本已经用实际构造处理掉的一般性警告。
