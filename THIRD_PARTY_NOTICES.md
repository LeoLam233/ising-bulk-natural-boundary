# Third-party materials

The repository does not redistribute the full external research PDFs, source page screenshots, operating-system instructions, model terms or fetched web pages. Citations and original URLs identify the external premises and prior work. The project licenses do not grant rights in those publications.

CR0 and MR1 input archives historically included external reference PDFs/text extracts. Their archive identities are recorded, but those whole archives are not placed in this public repository. The project-owned input instructions are published as views with the missing source identities documented. They are **not** advertised as byte-identical substitutes for the frozen input archives.

Historical AI audit and reproduction texts/code were supplied by the project operator. They remain labelled by their run/version and original hashes. Redacted views have separate hashes and transformation records; no certification or endorsement by a model provider or cited researcher is implied.

Runtime dependencies NumPy, SymPy, mpmath, Python and TeX tools are not bundled. Install them from their upstream distributions under their respective licenses. The MIT file covers project code; CC BY 4.0 covers project prose and manuscript. Licenses do not authenticate mathematics.
